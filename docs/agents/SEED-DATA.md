## Каталог услуг (`request_types`)
1. `certificate-study` — Справка об обучении · certificate · «Подтверждает, что вы учитесь: для военкомата, банка, работодателя» · 1 рабочий день · бесплатно · форма: recipient (select: «Военный комиссариат», «По месту требования», «Банк», «Другое»), copies (select 1/2/3), note (textarea, optional).
2. `certificate-scholarship` — Справка о стипендии · certificate · 2 рабочих дня · форма: period (select «За последний месяц», «За семестр»), recipient.
3. `certificate-visa` — Справка-вызов для визы / поездки · certificate · 3 рабочих дня · форма: country (text), embassy (text), dates (text).
4. `academic-leave` — Академический отпуск · application · 3 рабочих дня · форма: reason (radio: «Состояние здоровья», «Семейные обстоятельства», «Другое»), period (select «1 год», «2 года»), comment (textarea, ≥ 20 символов).
5. `individual-plan` — Индивидуальный учебный план · application · 5 рабочих дней · форма: course (course), reason (textarea), teacherOk (checkbox «Согласовано с преподавателями»).
6. `retake` — Пересдача по дисциплине · application · 2 рабочих дня · форма: courseCode (select, `type: 'select'`, opts []; в `request_types.dynamicOptions` = `studentCourses`), reason.
7. `grade-transcript` — Выписка из зачётной книжки · service · мгновенно · форма: semesters (select «Все», «Только текущий»). Авто-готово.
