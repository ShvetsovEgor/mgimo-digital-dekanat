# Задача агенту: виджет авторизации

Бриф фичи. Выполнять, когда просят переработать экран входа. Базовую сборку кабинета он не расширяет сам по себе.

Переработай блок авторизации в правой части экрана `/login` в виде компактного, визуально обособленного виджета-карточки (по аналогии с современными SSO-порталами). Цвета не задавай заново: бери текущие токены приложения из `docs/DESIGN.md` (`bg`, `surface`, `sidebar`, `line`, `brand`, `ink`, `muted`, `quiet`). Индиго и золото не использовать. Чужие и официальные логотипы вузов не использовать — только свой знак «конверт» из `web/src/components/Logo.tsx`.

Перед кодом прочитай `AGENTS.md`, `docs/DESIGN.md`, `docs/SECURITY.md`, `web/src/pages/LoginPage.tsx`, `web/src/components/ui/HeaderMenus.tsx`.

Границы задачи:

- Меняй вёрстку правой колонки `LoginPage`. Левую колонку с рассказом о кабинете на десктопе оставь.
- Не меняй `POST /api/auth/login`, cookie, `X-Tab-Session`, throttle и срок сессии. Настоящего SSO в прототипе нет: кнопка входа остаётся входом по логину и паролю и подписана «Войти».
- Чекбокс «Оставаться в системе» — часть виджета. Пароль в `localStorage` не писать, срок cookie не удлинять. Сессия остаётся как в `docs/SECURITY.md`.
- Демо-аккаунты бери из `GET /api/meta` (`accounts`). Не заводи логины «Студент А» / «Студент Б». В списке — имя и роль уже существующих аккаунтов (три студента и специалист деканата). Быстрый вход — текущий сценарий: подставить логин и пароль и сразу отправить форму.
- Переключатель темы и язык — те же механизмы, что в кабинете (`setStoredTheme`, язык с пометкой «скоро» у английского). Новые темы и перевод интерфейса не делай.
- Оставь состояния, которые уже есть: чужая вкладка уже вошла, сессия истекла, ошибка входа, долгий ответ сервера, скелет метаданных, дисклеймер концепта. Галерею скриншотов на экран входа не возвращай.
- Крупное скругление `24–28px` — только у карточек этого экрана. Остальной интерфейс остаётся на радиусе 12 из `docs/DESIGN.md`.

### 1. Геометрия и контейнер виджета

- **Форма:** самостоятельная карточка с крупным, мягким скруглением углов (`border-radius: 24px–28px`) и щедрыми внутренними отступами (`padding: 32px–40px`).
- **Контраст:** фон самой карточки должен слегка отличаться по тону от фона правой колонки, чтобы карточка читалась как отдельный «парящий» виджет. Тень не добавляй: отличие даёт фон и граница `1px` токена `line`.
- **Позиционирование:** центрирована по вертикали и горизонтали внутри правой колонки на десктопе; на мобильных (`360px+`) занимает всю ширину с аккуратными боковыми отступами (`16px`).

### 2. Внутренняя структура виджета (сверху вниз)

#### А. Верхняя строка (Header)

Горизонтальный flex-контейнер (`justify-content: space-between`, `align-items: center`) с заметным отступом вниз до заголовка (`margin-bottom: 40px–48px`):

- **Слева (бренд):** круглая иконка-логотип вымышленного сервиса (`36px–40px`) + двухстрочное название заглавными буквами справа от неё: «ДЕДЛАЙН» и «ЦИФРОВОЙ ДЕКАНАТ».
- **Справа (утилиты):** две компактные контурные кнопки (`border: 1px solid` с низкой прозрачностью), расположенные рядом с небольшим зазором (`gap: 8px–10px`):
  1. Квадратная кнопка со скруглением (`border-radius: 10px–12px`, `36x36px`) — переключатель темы (иконка луны/солнца).
  2. Прямоугольная кнопка со скруглением (`border-radius: 10px–12px`, высота `36px`) — выбор языка (иконка глобуса + `RU`).

Цели нажатия не ниже 44px: визуальный размер кнопки темы может быть 36px, зона клика — не меньше 44px.

#### Б. Заголовочный блок

Выравнивание по левому краю, отступ вниз до полей (`margin-bottom: 24px`):

- **Заголовок:** крупный жирный текст **«Авторизация»** (`24px–28px`).
- **Подзаголовок (в одну строку под заголовком):** мелкий текст `студенческий портал` + акцентный домен вымышленного сервиса `deadline.university`.

#### В. Форма входа и главная кнопка

- **Поля ввода (Логин и Пароль):** компактные, на всю ширину карточки, с единым скруглением (`border-radius: 10px–12px`), встроенной иконкой показа пароля и аккуратным чекбоксом «Оставаться в системе».
- **Главная кнопка действия:** на всю ширину карточки, заметная по высоте (`46px–50px`), со скруглением (`border-radius: 10px–12px`). Внутри по центру — круглая мини-иконка + жирный текст **«Войти»**.

Подписи полей, ошибки валидации и `autocomplete` сохрани: логин `username`, пароль `current-password`.

### 3. Вспомогательный виджет «Демо-доступы для жюри»

- Размести его **отдельной компактной карточкой** с таким же скруглением (`border-radius: 20px–24px`) чуть ниже основного виджета авторизации (`gap: 16px`), чтобы не перегружать форму входа.
- Внутри — лаконичный список тестовых аккаунтов из `meta.accounts` с кнопками быстрого входа в 1 клик. Пока метаданные грузятся — скелет. Если список не пришёл — короткая ошибка с «Повторить», форма входа при этом работает.

После правки: `npm run build -w web`. В браузере проверь `/login` на ширине 360px и на десктопе: вход Анной (`a.ivanova`), быстрый вход сотрудником деканата, переключение темы, ошибка пустого пароля. Левая колонка на десктопе остаётся на месте, на 360px экран не скроллится по горизонтали.
