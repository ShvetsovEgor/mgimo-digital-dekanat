# Правила зачётов (публичный регламент)

Источник: https://mgimo.ru/study/akadrating/poryadok-zachetov.php (текст получен 17.11.2026)

Ключевое для кабинета:
- Итоговая оценка за работу в семестре (по результатам контроля знаний) **≥ 70%** → возможен «автоматический» зачёт.
- Оценка за «автоматический» зачёт соответствует итоговой оценке за работу в семестр (в %).
- Студенты с рейтингом ниже 70% допускаются к традиционному зачёту; их рейтинговые оценки за зачёт не могут превышать 70%.
