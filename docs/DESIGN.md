# DESIGN — визуальная система «Дедлайн»

Источник облика — два кадра светлого кабинета (главная и недельное расписание): узкая сиреневато-серая колонка, белый холст, один фиолетовый акцент, плоские карточки, пастельные блоки занятий. Цвета сняты с кадров и из‑за масштаба скриншотов являются рабочей палитрой.

Это визуальный источник истины для UI. Индиго `#1D3A8A` и золото `#C9A227` не используются.

Жёсткие ограничения проекта, которые кадры не отменяют:

- Знак свой: конверт «Дедлайн». Слово `inh` и любые логотипы университетов не копировать.
- Язык интерфейса — русский. Короткие английские имена разделов с кадров не переносить.
- Шрифт — Manrope (OFL, latin + cyrillic). По характеру это тот же спокойный гротеск, что на кадрах.
- Тач-цели ≥ 44 px, mobile-first 360 px, контраст AA, `prefers-reduced-motion`.
- Тёмная тема на кадрах не показана (виден только переключатель). Её строим из этих же ролей: тёмный холст, светлые чернила, акцент светлее `#9154EB`. Пастель занятий приглушать, не заменять индиго.

## Характер

Интерфейс тихий. Поверхности разделяются фоном и волосяной границей, без теней и без фоновой плашки у пункта меню. Акцент `#9154EB` — ссылки, активный пункт, иконки карточек, бейдж, обводка поиска. Текст — чернила `#1C1B23` и серый. Пастель живёт только в сетке расписания.

## Цвет

| Роль | Токен | Где |
|---|---|---|
| Акцент | `#9154EB` | Активный пункт, иконки карточек, ссылки, бейдж, обводка поиска |
| Акцент при нажатии | `#7A3AD4` | Hover ссылки и активного пункта |
| Чернила | `#1C1B23` | Заголовки, имя, подписи занятий |
| Текст второй | `#6E6874` | Описания, почта, дедлайны |
| Текст тихий | `#8A8490` | Сноски, плейсхолдер, неактивный фильтр |
| Холст | `#F7F6F8` | Фон страницы |
| Колонка | `#F3F1F4` | Сайдбар |
| Поверхность | `#FFFFFF` | Карточки |
| Поверхность hover | `#ECEAEF` | Карточка под курсором |
| Граница | `#E6E3E8` | Карточки, разделители колонки |

| Сейчас | `#B71E20` | Линия текущего времени |

Акцент на белом ≈ 4.5:1 — для ссылок и бейджа. Абзацы писать `#1C1B23` или `#6E6874`. `#8A8490` только для сносок и плейсхолдера.

Пастель занятий. Один предмет — один цвет на лекции, лабораторные и тьюториалы. Текст на пастели всегда `#1C1B23`. Тип занятия цветом не кодировать: он пишется в скобках `(лек)`, `(лаб)`, `(практ)`.

| Роль на референсе | Заливка |
|---|---|
| Лиловый предмет | `#C0ABD4` |
| Серо-зелёный предмет | `#A8B8B8` |
| Бирюзовый предмет | `#BCD7D8` |
| Зелёный предмет | `#A5D0A5` |
| Пыльная роза | `#D49699` |

Новому предмету давать следующий свободный пастельный тон той же светлоты (заливка примерно 75–85% яркости), чтобы чернила оставались читаемыми.

Manrope. Логотип — отдельный знак конверта цветом акцента, рядом слово «Дедлайн».

## Пространство и форма

Базовый шаг 4. Рабочие отступы: 8, 12, 16, 24, 32.

- Сайдбар 176px на десктопе. Внутренний отступ 12px по горизонтали, 8px между пунктами. На 360px колонка не стоит в потоке: выезжающая панель или нижняя навигация, без горизонтального скролла.
- Поле страницы 24px (16px на 360px).
- Карточки в ряд с зазором 12px. Внутренний паддинг карточки 16px.
- Радиус карточки 12px, поля поиска 10px, блока занятия 8px, аватара и бейджа — полный круг.
- Иконка в меню 18px, в карточке 20px, внешний переход 14px. Обводка 1.75px, скруглённые концы. Lucide.
- Цель нажатия ≥ 44px у пунктов меню, иконок шапки и ссылок-действий.

Тени нет. Карточка отделяется `1px solid #E6E3E8`. Поиск — поле с постоянной обводкой акцента.

## Оболочка

**Колонка.** Сверху свой знак. Дальше список: иконка и подпись в одну строку. Активный пункт — акцент на иконке и на тексте, без фоновой плашки. Неактивный — чернила. Группы разделены линией `#E6E3E8` с отступом 12px. Хвост колонки прижат к низу. Внешний сервис получает справа иконку внешнего перехода цветом `#8A8490`.

Короткий бейдж статуса: фон `#9154EB`, текст белый, высота 16px, паддинг 0 6px.

**Шапка.** На холсте, без собственной подложки. Слева иконка сворачивания колонки и заголовок страницы. Справа язык, переключатель темы, круглый аватар 32px. Зазор 12px.

## Компоненты

**Профиль.** Аватар 40px (если нет фото — инициалы на `#F3F1F4`). Справа имя; вторая строка — серая мета; третья — контакт тем же серым.

**Информационная карточка.** Белая, радиус 12px. Слева сверху контурная иконка акцента, заголовок 14/600. Дальше 1–3 строки `#6E6874`. Действие — текстовая ссылка акцента, без подчёркивания; внешний переход — с иконкой. Пустое состояние — одно предложение и ссылка, без иллюстрации.

**Ссылка-действие.** Акцент, 14/500, без подчёркивания. Навигация вглубь может начинаться со стрелки. Подчёркивание только по наведению.

**Каталог.** Заголовок секции слева, поиск справа, одна линия. Сетка карточек. Справа колонка фильтра около 160px, без карточки: заголовок 14/600 и список. Активный фильтр — акцент, остальные — `#6E6874`, без плашки. Под сеткой по центру текстовая кнопка «Показать все (N)», без рамки.

**Поиск.** Высота 44px, радиус 10px, обводка `1px solid #9154EB`, фон белый, плейсхолдер `#8A8490`, паддинг 0 12px.

**Карточка сервиса.** Иконка акцента, заголовок, описание до двух строк `#6E6874`. Hover — заливка `#ECEAEF`, граница та же.

Прямоугольных кнопок на референсных экранах нет: основное действие — ссылка. Компонент `Button` в продукте остаётся для форм (вход, отправка, опасное действие): primary — заливка `#9154EB`, текст белый; вторичная — белая с границей `#E6E3E8`; опасная — `#B71E20`.

## Расписание

Неделя — вертикальный день с раннего утра до позднего вечера, не обрезанный только под пары. Слева колонка часов 56px: `HH:00` цветом `#8A8490`, 12px, по линии часа. Дальше равные колонки дней. Линии `#EEEEF0`, 1px. Подписи дней — над колонками, 13/600.

Блок занятия:

- заливка предмета, радиус 8px, отступ от линий колонки 3px;
- паддинг 6px 8px;
- название 12/600, до двух строк, дальше многоточие;
- тип в скобках в той же строке;
- следующей строкой интервал;
- последней строкой аудитория.

Соседние занятия не слипаются: между ними виден просвет сетки. Линия «сейчас» — 2px `#B71E20` по ширине колонки текущего дня, поверх сетки.

## Состояния

- Активный раздел: цвет акцента, фон пункта не меняется.
- Наведение карточки: заливка `#ECEAEF`.
- Пусто: одно предложение и ссылка.
- Загрузка: скелет на белой карточке, без спиннера на весь экран.
- Ошибка: текст `#6E6874` и действие «Повторить». Новый акцентный цвет для ошибок не вводить; опасное — `#B71E20`.
- Внешний переход: иконка рядом с текстом, текст остаётся в потоке.

## Тон

Коротко. Заголовок карточки несёт факт. Вторая строка — уточнение или срок. Сноска мелкая. Ошибки говорят, что сделать. В футере и на входе остаётся дисклеймер: концепт для конкурса, не официальный сервис, данные вымышлены.

## Экран входа (`/login`)

Исключение из общего правила радиусов: карточки этого экрана — 26 px (виджет авторизации) и 22 px (демо-доступы),
остальной интерфейс остаётся на 12 px. Фон левой колонки — сменяющиеся кадры кампуса (сгенерированы ИИ,
`web/public/backdrops`), кроссфейд 9 с, при `prefers-reduced-motion` — статичный кадр. Тень не используется:
карточка отделяется фоном `surface` и границей `line`.
