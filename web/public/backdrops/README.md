# Фоны экрана входа

Три кадра кампуса сгенерированы ИИ (Gemini) специально для концепта «Дедлайн».
Полноразмерные исходники — в `static/` (не коммитятся), веб-версии здесь сжаты до 1600 px по ширине
(JPEG q72, 200–290 КБ) и меняются кроссфейдом раз в 9 секунд.

Реальные вузы, логотипы и товарные знаки не используются: кампус и вывески — вымышленные.
