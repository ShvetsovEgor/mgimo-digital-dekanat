# AGENTS.md — правила работы ИИ-ассистентов над проектом «Цифровой деканат 2030»

Этот файл читают **все** ИИ-агенты (Codex/DeepSeek Harness, subagents, Codex Cloud) перед началом работы.
Читать порядок: этот файл → `docs/SPEC.md` → `docs/DESIGN.md` (для UI) → `docs/DATA.md` (для данных).

## 1. Что мы строим

Рабочий прототип личного кабинета студента МГИМО («Цифровой деканат 2030») для конкурса
«Кибербезопасность и ИИ в высшей школе — 2026» (VK Education).

- Это **концепт для конкурса**, а НЕ официальный сервис университета и НЕ подключён к системам МГИМО.
- Только вымышленные данные. Никаких реальных ФИО, номеров зачёток, телефонов, e-mail реальных людей.
- Логотип университета не используется — только собственный логотип «Дедлайн».
- Язык интерфейса и комментариев в коде — русский. Код — TypeScript, строгий.

## 2. Стек (НЕ менять без явного решения)

| Слой | Технологии |
|---|---|
| Backend | Node.js 24, Express 5, TypeScript, better-sqlite3 (SQLite, WAL), zod, pdfkit, библиотеки `node:crypto` |
| Frontend | Vite, React 19, TypeScript (strict), React Router 7, TanStack Query, Tailwind CSS v4, Lucide React |
| Шрифты | Manrope (кириллица), Google Fonts |
| Документы | PDF генерируются на сервере (pdfkit), QR подписан HMAC |
| Монолит | `server` раздаёт API `/api/*` и собранный фронт из `web/dist` |

## 3. Структура репозитория

```
server/        Express API, RBAC, БД, seed, PDF-документы
web/           SPA (React), мобильный-first
docs/          SPEC.md, DESIGN.md, DATA.md, SECURITY.md, report/ (документ о процессе)
scripts/       вспомогательные скрипты (screenshots, smoke-тесты)
deploy/        Dockerfile, описания деплоя
```

## 4. Жёсткие требования (definition of done)

1. **Работает всё ядро**: вход/выход, профиль, расписание (сегодня/неделя/изменения), успеваемость (оценки, зачёты, сессия, рейтинг), заявки и справки (заказ, статус, PDF), уведомления.
2. **Mobile-first**: всё работает на ширине 360 px, тач-цели ≥ 44 px, нет горизонтального скролла.
3. **Безопасность** (см. `docs/SECURITY.md`):
   - пароли только bcrypt (cost ≥ 10), в БД нет открытых паролей;
   - сессия — серверная, cookie `__Host-*`/`HttpOnly; Secure (prod); SameSite=Lax`;
   - **любой** ресурс проверяется на принадлежность текущему пользователю на сервере (IDOR закрыт);
   - секреты только через env, `.env` в `.gitignore`, на клиент секреты не попадают.
4. **Пустые состояния, ошибки, загрузка** проработаны для каждого экрана.
5. **Доступность**: контраст AA, focus-visible, `aria-label` на иконках-кнопках, навигация с клавиатуры, `prefers-reduced-motion`.
6. Только лицензии, разрешающие использование (MIT/ISC/Apache-2.0/OFL).
7. Никаких `any` без причины; никаких секретов в коде.

## 5. Стиль кода

- API возвращает JSON `{ ok: true, data }` или `{ ok: false, error: { code, message } }`.
- Ошибки — только через `ApiError(status, code, message)`.
- Все входные данные валидируются zod-схемой на сервере.
- В React: компоненты < 250 строк, логика — в `lib/`, UI-примитивы — в `components/ui/`.
- Никаких `console.log` в прод-пути (только `server/log`), PII не логируется.

## 6. Как отчитываться

После каждой задачи агент пишет короткое резюме: что сделано, какие файлы, как проверить
командой (`npm run build`, `npm test`, `npm run smoke`), какие известные ограничения.
